# Ortsnetz Map Card 1.0.0

Erstes stabiles Release der Dashboard-Card.

Highlights:

- Home-Assistant-Standort als Standard-Mittelpunkt
- UI-Konfiguration ohne YAML-Zwang
- Zoom 10 als Standard
- Größe nur über HA Layout inklusive **Full Width**
- automatischer Dark Mode nach HA-Theme
- Messpunkte über das separate Backend

Nach dem HACS-Update die Home-Assistant-App bzw. Browserseite vollständig neu laden.
